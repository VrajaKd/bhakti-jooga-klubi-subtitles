Privacy Policy: Bhakti Jooga Klubi Subtitles

Last updated: 2 October 2026

Who uses this tool

Bhakti Jooga Klubi Subtitles is a private tool operated only by the owner of the YouTube channel Bhakti jooga klubi, for that channel's own videos. It has no other users.

What data it accesses

With the channel owner's consent, the tool uses the YouTube Data API to read and update the channel's own videos: caption tracks, titles, descriptions, tags and video localizations. It does not access any other user's data.

How the data is used and stored

The data is used only to add and correct subtitles and translations on the channel's videos. The OAuth access token and the working files are stored only on the channel owner's own computer. Nothing is sold, shared with third parties or used for advertising.

Revoking access

Access can be revoked at any time in the Google Account under Security: Third-party apps with account access.

YouTube and Google

This tool uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Contact
